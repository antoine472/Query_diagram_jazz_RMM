Widget SafranArchitecture Query Diagram - version 2026d2 (30/10/2026)

Contenu de cette version :
  - Toutes les fonctions de la 2026d (choix GC, baselines, memoire des choix, vues Tables
    et Matrices, prefixe proprietaire des Operating Mode Charts, copies heritees masquees)
  - Vue Diagrams refaite :
      * onglets All / A Operational / B Functional / C Logical / D Technical, avec le
        nombre de diagrammes et le nombre de types qui en ont ; dernier onglet memorise
      * tableau : type (affiche reduite), nom, date de modification, owner, actions
      * une ligne de filtres sous l en-tete (texte contenu, sans tenir compte des
        majuscules) ; le texte trouve dans le nom est surligne ; les filtres restent
        actifs quand on change d onglet
      * en-tete et filtres restent visibles pendant le defilement
      * types sans diagramme rappeles sous le tableau
  - Date de modification et owner : champs modified et modifiedBy du reporting (aucune
    requete en plus). La date est affichee en heure locale. Owner = dernier auteur de la
    modification (le reporting ne donne pas le createur).
  - Nouveau type affiche : Functional Sequence Diagram (onglet B, pastille rouge faute
    d affiche)
  - Pas de regroupement des custom views : RMM ne publie aucun lien entre un diagramme
    et ses vues filtrees (verifie le 30/10/2026 sur IP2 - FETT et Vue filtree)

Fichiers modifies par rapport a la 2026d (a copier sur le serveur, en remplacant les anciens) :
  Safran_QueryDiagram.xml
  Safran_QueryDiagram.html
  js/safran-controller.js
  css/grid.css
js/global.configuration.js et css/fonts/ sont identiques a la 2026d. Les autres fichiers du
widget (js/ELM_utils.js, js/types.js, js/safran-query-diagram.js, bibliotheques,
resources/) ne changent pas.

Controle : la page affiche "Widget version : 2026d2" et les onglets All / A / B / C / D.

de nouveau avec l adresse .../Safran_QueryDiagram.xml?v=2026d2
